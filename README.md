
# Student Marks Analyzer

## About
A beginner-friendly Python project that calculates student total marks, average, and pass/fail result.

## Features
- Takes student name and marks as input
- Calculates total and average
- Validates marks between 0 and 100
- Handles invalid numeric input
- Displays Pass or Fail

## Technologies Used
- Python 3

## How to Run
1. Install Python 3.
2. Open the terminal in the project folder.
3. Run `python marks_analyzer.py`.

## Learning Outcomes
- Python variables and input
- Loops and conditional statements
- Exception handling
- Lists and calculations
